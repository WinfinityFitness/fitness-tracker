            0:00 / 0:00
              AI estimates work out of the box — no key required. Both "Estimate with AI" and "Estimate from Photo" run on Winfinity's shared free pool by default; you only need your own Gemini API key (Menu → Settings, see Tutorial 2) to get your own quota instead of sharing the pool. Every AI estimate comes back flagged "low accuracy, review before saving" for a reason — treat it as a starting point, not gospel. One real gotcha caught on camera: tapping too close to a search result re-selects it and resets your unit/serving changes — the actual "Add to diary" button is the one below the warning box, not the one right under the result list.
